# Insurance-Data-Analysis

## Project Overview

This project focuses on analyzing insurance data to identify customer patterns, understand insurance-related trends, and generate meaningful business insights using Python.

## Objective

- Analyze customer and insurance data
- Perform data cleaning and preprocessing
- Explore customer patterns and trends
- Create meaningful data visualizations
- Generate business insights from the dataset

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses a cleaned insurance dataset containing 50,000 customer records.

The cleaned dataset is available in:

cleaned_ins_data_50k.csv

## Project Workflow

1. Data Loading
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Customer & Insurance Data Analysis
5. Data Visualization
6. Business Insights

## Key Analysis

The analysis includes:

- Customer demographic analysis
- Marital status distribution
- Insurance-related patterns
- Customer segmentation
- Frequency analysis
- Data visualization using charts and graphs

## Key Insights

The project helps identify customer patterns and trends that can support better business decision-making and customer targeting.

## Project Files

- Ins_Project V2.ipynb – Complete Python analysis
- cleaned_ins_data_50k.csv – Cleaned dataset
- README.md – Project documentation

## Conclusion

This project demonstrates the use of Python and data analysis techniques to clean, analyze, visualize, and derive insights from real-world insurance data.
