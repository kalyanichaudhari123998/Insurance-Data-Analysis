# Insurance-Data-Analysis

## Project Overview
This project focuses on analyzing insurance data to identify customer patterns and generate meaningful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Work
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer and insurance data analysis
- Data visualization
- Generating insights from the dataset

## Dataset
Insurance dataset containing 50,000 records.
